# Metstrade 2026 — GitHub testing website

This ZIP contains the complete responsive website, including its photos, local fonts, delegate map and business profiles PDF.

## Upload to GitHub Pages

1. Unzip this package.
2. Upload the extracted files and folders to the root of your chosen repository branch. Upload the contents, rather than the ZIP itself or an extra enclosing folder.
3. Keep `index.html`, `map.html` and `assets/` together. Keep `.nojekyll` if your uploader includes hidden files.
4. In the repository, open Settings > Pages. Choose Deploy from a branch, your branch and /(root), then save.
5. Open the Pages URL once GitHub finishes publishing.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

There is no build step or installation required. One version handles both desktop and mobile. Relative paths support a GitHub repository subfolder.

The fixed business order starts DockPro, Stella Marine Group, Safiery, Sanctuary Cove Marina and Southern Seas Marine. Mobile uses a looping swipe deck including the intro and resources card; desktop uses the scrolling deck.

The technical handoff ZIP contains the identical website plus editable source and integration notes for your developer.
